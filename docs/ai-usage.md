# My Personal AI Usage Rules

## Rule 1 - What I will never paste
I will never paste secrets, private credentials, personal data, or proprietary source code from external systems into AI prompts or responses.

## Rule 2 - What I will always verify before accepting
I will always verify output for correctness, security, and alignment with project conventions before accepting or merging changes.

## Rule 3 - How I will record AI contributions
I will record AI-generated changes in commit messages or documentation notes, and I will note when I reviewed or revised the AI’s suggestions.
